# TuOS

A clean macOS-style desktop running in your browser, built with vanilla HTML, CSS, and JavaScript.

👉 **Live Demo:** [https://tudustech-hub.github.io/TuOS/](https://tudustech-hub.github.io/TuOS/)

---

### Features

- **Setup & Lock Screen**: Onboarding wizard, lock screen with password
- **Top Bar**: Center clock with date. Click it to open the calendar and quick timer.
- **Dock**: To access your apps easily ( right click to remove/add )
- **Apps**:
  - **Clock**: Timer and stopwatch.
  - **Weather**: hourly forecast.
  - **Notes**: text....
  - **Calculator**: Quick math.
  - **Finder & Launchpad**: App launcher.
- **Control Center**: Screen brightness and toggles.
