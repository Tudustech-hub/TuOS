# TuOS

A macOS-inspired WebOS that runs in your browser built with just vanilla HTML, CSS and JavaScript. No heavy frameworks. No extra code. Just clean simple working code.

### Try it here:
**[https://tudustech-hub.github.io/TuOS/](https://tudustech-hub.github.io/TuOS/)**

---

## What’s in it?

- **Setup Assistant**: Appears the time you open TuOS. It guides you through setting your username, password and country.

- **Lock Screen**: Password protected. If you get it wrong the screen shakes a little— like real macOS.

- **Top Bar & Clock**: Shows the date month and time in the center. Click it to open a glassy calendar that updates every second.

- **Control Center & Menu**: access to brightness, Wi-Fi lock screen and system reset. All in one place.

- **Dock & Windows**:

Windows move smoothly with drag-and-drop. They run at 60 FPS using 3D transforms so it feels smooth.

The dock has a fisheye zoom when you hover over it. Apps bounce slightly when you open them. It adds a touch.

- **Built-in Apps**:

**Notes**: Every word you type is saved automatically. No need to press save.

**Calculator**: Does math. Addition, subtraction, multiplication, division—everything works.

**Weather**: Shows weather and hourly forecast. It updates in time.

**. Launchpad**: Browse apps easily. Launchpad shows everything in a grid. Click to open.
